# 후보 대기열

매일 도는 탐색 작업(`daily-strategy-search`)이 여기서 후보를 골라 하루에 하나씩 검증한다.
판정은 레지스트리(`ops/research/hypotheses.json`)에 남고, 여기에는 상태만 적는다.

상태: `대기` · `진행` · `완료(기각)` · `완료(모의검증)` · `사전심사 탈락`

## 사전 심사 기준 (2026-09-20, GPT-5.5 9차 상의)

하나라도 걸리면 검증하지 않는다.

1. 기존 기각 가설에 작은 필터를 더한 것
2. 강제 수급의 원인을 설명하지 못하는 것
3. 월별 사건 수 × 건당 NAV × 건당 기대수익으로 월 3%가 산술적으로 불가능한 것
4. 숏인데 손절이 작동할 수 없는 구조(점프가 열려 있는 신규 상장류)
5. 계정 생성이나 API 키가 필요한 데이터
