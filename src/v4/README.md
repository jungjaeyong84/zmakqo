# V4 — Cross-Sectional Momentum Paper Lane

`v4`는 `v3`의 재작성이 **아니다**. v3 인프라(원장 패턴·게이트·데드맨·백업·
maker-first)를 그대로 쓰되, **엣지 클래스 자체를 바꾼** 별도 레인이다.

| | v3 | v4 |
|---|---|---|
| 예측 대상 | 개별 심볼의 **절대 방향** | 심볼 **상대 순위** |
| 시간축 | 15m | 일봉 |
| 시장 노출 | 방향성 (상관 숏 클러스터) | **시장중립** (롱/숏 동수) |
| 결정 | 진입 시점마다 | 하루 1회 리밸런스 |
| 상태 | 자금 기준 **실패** (2026-07-31) | **페이퍼 전진검증 중** |

## 왜 v4인가 — v3의 사망 원인

v3의 문제는 코드가 아니라 **선택한 엣지 클래스**였다. 15분 방향성 예측은
5번의 독립 측정에서 전부 사망:

1. 진입 feature 판별 — out-of-sample 상관 0
2. RR sweep — WR≥50%+수익 동시 만족 불가
3. exit 오버레이 — 50% 달성 변형이 expectancy 붕괴
4. 심볼별 train/test — 양쪽 양수 심볼 0개
5. 일봉 TSMOM / 레짐 게이트 — 최근 16개월 전부 음수

최종: post-filter n=227에서 gross expectancy +0.063R, **95% CI
[-0.089, +0.215] = 0과 구별 불가**, 비용차감 -0.056R(taker)/-0.030R(maker).
자금 기준(n≥180 & 비용차감>0) **공식 실패**.

`scripts/analyze-v4-edge-classes.js` + `analyze-v4-cross-sectional.js`

핵심 검증:
- **랜덤 대조군 -42%/yr** → 실제 순위 신호가 정보를 담음 (v3 feature는 이
  테스트를 통과한 적이 없음)
- **maker-first가 +7%/yr를 만든다** — 2026-07-24에 만든 그 인프라가 여기서
  직접 작동. 0.30% 고비용 가정에선 -6.8%로 죽으므로 **체결 품질이 생명선**
- 시장중립이라 낙폭이 매수보유의 1/4

### 자기검증 (레드팀, `scripts/analyze-v4-placebo-control.js`)

빌드 직후 내 근거를 스스로 공격했고, 2개는 살아남고 1개는 결함으로 드러났다.

**① 회전율 일치 위약 대조군 — 통과 (가장 강한 증거)**
최초 근거였던 "랜덤 셔플 대비 +50%p"는 **오염된 주장**이었다. 매일 랜덤
순위는 회전율이 폭증하므로 그 -42%는 대부분 비용 드래그였다. 공정한 위약:
**실제 순위·회전율·포지션 구조는 그대로 두고 심볼↔수익 대응만 영구 치환**.
정보만 파괴하고 비용은 보존.

| | 연환산 |
|---|---|
| 실제 | **+22.7%** |
| 위약 40회 | 평균 -8.9%, p90 +5.1%, **최대 +14.5%** |

실제가 **40/40 위약을 전부 상회** (경험적 p ≈ 0.02). 이 프로젝트 3개월
통틀어 가장 강한 통계적 증거다. v3의 어떤 feature도 이 테스트를 통과한 적이
없다.

**② 순위 밴드 프로파일 — 부분적 약점**
진짜 모멘텀 팩터는 극단 순위에서 가장 강해야 하는데:

| 밴드 | 연환산 | Sharpe |
|---|---|---|
| 1-2위 (극단) | +4.5% | 0.30 |
| 3-4위 | **+9.2%** | 0.47 |
| 5-6위 (중간) | **-37.8%** | -1.72 |

중간 밴드가 파괴적으로 나쁜 것은 팩터 예측과 일치하지만, **극단이 가장
강하지는 않다**. 엣지가 넓게 퍼져 있다는 뜻 — 교과서적 팩터보다 약한 형태.
k=2가 나쁘고 k=4가 좋은 이유도 이것으로 설명된다(1-4위 결합이 1-2위 단독보다
낫다).

**③ 벤치마크 누락 — 내 기준의 실제 결함**
원래 기준(연 +8%, Sharpe 0.5)은 **거래하지 않는 대안**을 무시했다. 스테이블
예치 ~5%가 무위험으로 존재하는데, 연 8%를 24% 변동성으로 버는 것은 나쁜
거래다. 아래 기준을 **excess 기반으로 상향**한 이유다.

**남은 정직한 약점**:
- 최근 구간(2025 +5.4%, 2026 +9%)은 무위험 대비 초과가 얇다
- universe 구성에 따라 2024년 부호가 뒤집힘
- 전부 백테스트. **전진 검증 0**
- 소자본에선 연 몇 %가 절대금액으로 무의미

## 사전 확정 기준 (2026-08-01, forward 데이터 존재 이전에 확정)

v3의 교훈 — 기준은 데이터를 보기 **전에** 못 박는다. 사후 합리화 금지.

```
90일 forward paper  AND  무위험(5%) 대비 초과수익 >= +8%p
                    AND  excess Sharpe >= 0.5
                    AND  최대낙폭 >= -20%
```

> 기준은 같은 날 **한 번 상향 조정**됐다(절대 → 초과 기준). forward 데이터가
> 아직 0인 시점이었으므로 결과에 맞춘 조정이 아니며, 방향도 **완화가 아닌
> 강화**다. 이후 조정은 골대 옮기기로 간주한다.

미달 시 **v4도 v3처럼 폐기**한다.

## 구성

| 파일 | 역할 |
|---|---|
| `crossSectionalSignal.js` | 순수 로직 — 순위/포지션, 실현수익·비용 회계 |
| `scripts/run-v4-paper-rebalance.js` | 일 1회 리밸런스 → `v4_paper_rebalance_ledger.jsonl` |
| `scripts/report-v4-paper-performance.js` | 사전 확정 기준 대비 채점 |
| launchd `v4paper` | 09:17 KST (= 00:17 UTC, 일봉 마감 직후) |

**두 universe 변형을 병렬로 돌린다.** 백테스트가 어느 쪽이 나은지 모순된
답을 줬으므로(12종은 2024, 27종은 2026) 지금 하나를 고르면 그것이 곧
과적합이다. 페이퍼는 공짜이니 둘 다 전진시키고 **미래 데이터가 고르게** 한다.

- **페이퍼 전용.** v4에는 실행 레이어가 의도적으로 없다. 돈 이야기는 위
  기준 충족 이후에만.

- 데드맨 5번째 심박으로 등록 (26h 허용)
