# DONBEOLJA Product Overview

## 한 줄 설명
돈벌자는 서버가 자동으로 코인 선물 신호를 만들고 거래를 수행하며, 사용자는 자산·수익·신호·전략 상태를 한 화면 체계에서 확인하는 자동 코인 선물 거래 시스템이다.

## 무엇을 해결하는가
자동 거래 시스템은 보통 아래 문제가 있다.
- 신호가 어디서 만들어졌는지 불명확하다.
- 거래는 돌아가는데 사용자는 현재 상태를 이해하기 어렵다.
- 수익과 손실은 보이지만 왜 그런 결과가 났는지 연결이 안 된다.
- 전략이 진화하고 바뀌어도 차트에서 직접 확인하기 어렵다.

돈벌자는 이 문제를 다음 방식으로 해결한다.
- 서버가 정본 신호를 생성하고 실행한다.
- 사이트에서 자산, 수익, 신호, 드롭, 전략 상태를 한 번에 본다.
- Pine는 차트 시각화와 비교 검증용으로 유지한다.
- 자연 진화 상태와 서버 우선 전환 상태를 운영자가 아닌 사용자도 읽을 수 있게 보여준다.

## 자동 코인 선물 거래에서의 역할
돈벌자는 단순한 차트 보조 도구가 아니다. 역할은 크게 다섯 가지다.
1. 시장 데이터를 읽는다.
2. 서버에서 정본 신호를 만든다.
3. 주문 의도와 실행으로 연결한다.
4. 결과를 수익과 거래 기록으로 집계한다.
5. 전략 품질과 자동 진화 상태를 계속 추적한다.

## 사용자에게 보여줘야 하는 핵심 정보
사이트에서 사용자가 최소한 확인해야 하는 정보는 아래 다섯 축이다.

### 1. 자산
- 현재 총자산
- 가용 자금
- 사용 중 자금

### 2. 수익
- 오늘 손익
- 최근 7일/30일/6개월 손익
- 누적 손익
- 어떤 마켓이 성과에 기여했는지

### 3. 신호
- 최근 정본 신호
- 최근 신호 등급
- 최근 신호 발생 시각
- 최근 신호가 실제 체결로 이어졌는지

### 4. 드롭
- 최근 드롭 수
- 주요 드롭 사유
- 어떤 정책 때문에 실행되지 않았는지

### 5. 전략 상태
- 서버 우선 전환 진행률
- 정본 신호 상태
- Pine 그림자 비교 상태
- 자연 진화 상태
- 다음 자동 조치

### 6. 설정
- 거래소 설정
- 리스크 설정
- 실행 모드 설정
- AI/자동화 설정

## 서버 정본 / Pine 그림자 구조
돈벌자는 신호 체계를 두 층으로 나눈다.

### 서버 정본
서버는 실제 거래 기준이 되는 신호를 만든다.
- Binance 봉 데이터를 읽는다.
- 전략 규칙으로 LONG/SHORT 진입 신호를 계산한다.
- 주문 의도, 체결, 거래로 이어진다.
- UI, Telegram, 자동화 판단은 서버 정본을 기준으로 한다.

### Pine 그림자
Pine는 실행 정본이 아니다.
- 차트에서 신호 구조를 시각화한다.
- 서버 신호와 비교한다.
- 사용자가 TradingView에서 직접 체감 검증하도록 돕는다.
- 자동 진화로 신호 체계가 바뀌면 Pine도 항상 같이 갱신된다.

## 왜 Pine가 여전히 필요한가
서버가 정본이더라도 Pine는 계속 필요하다.
1. 사용자가 차트에서 직접 신호 위치를 확인해야 한다.
2. 서버 정본과 Pine 그림자를 비교해야 전환 품질을 검증할 수 있다.
3. 자동 진화로 규칙이 바뀌면 실제 차트 체감이 유지되는지 확인해야 한다.

즉 Pine는 없어지는 것이 아니라 역할이 바뀐다.
- 과거: 신호 발생기
- 현재/미래: 시각화와 비교용 shadow

## 사용자가 사이트를 읽는 방식
새 사이트는 아래 순서로 읽히게 설계한다.

### 홈
질문: 지금 내 돈과 거래 상태가 어떤가
- 총자산
- 오늘 손익
- 최근 신호
- 최근 체결
- 전략 상태 요약

### 수익
질문: 얼마나 벌고 있고, 어느 기간에서 좋아졌나
- 기간별 손익
- 누적 성과
- 주요 기여 마켓

### 거래기록
질문: 신호가 나왔나, 드롭됐나, 주문과 체결은 됐나
- 최근 신호
- 최근 드롭
- 주문/포지션
- 최근 체결

### 전략상태
질문: 전략은 정상인가, 왜 아직 완전히 전환되지 않았나
- 서버 우선 전환 진행률
- 정본/그림자 비교
- 드리프트 원인
- 실행 품질
- 다음 자동 조치

### 설정
질문: 현재 운영 기준은 무엇이며 무엇을 바꿀 수 있는가
- 거래소
- 리스크
- 실행 모드
- AI/자동화

## 현재 방향
돈벌자는 현재 아래 방향으로 전환 중이다.
- Pine 중심 신호 구조에서 서버 정본 구조로 이동
- 운영자 콘솔 같은 화면에서 사용자 중심 거래 제품 화면으로 이동
- 수익 페이지를 기준으로 전체 UX를 재구성
- 기존 사이트는 legacy 백업으로 유지

## 최종 목표
최종적으로 돈벌자는 아래 구조를 갖는다.
- 서버가 Binance 데이터를 읽고 직접 신호를 생성한다.
- 서버가 실행과 결과 기록의 기준이 된다.
- 사용자는 사이트에서 자산, 수익, 신호, 드롭, 전략 상태를 쉽게 읽는다.
- Pine는 TradingView에서 최신 전략을 보여주는 시각화 shadow로 유지된다.
