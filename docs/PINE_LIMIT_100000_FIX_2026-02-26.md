# Pine `100000 limit` 초과 대응 체크리스트 (2026-02-26)

## 문제
- 컴파일 오류: `100964. The limit is 100000`
- 의미: Pine 코드 토큰/구문량이 한도를 넘음

## 이번 적용 내용(2차)
- 대상 파일: `code/donbeolja.pine.txt`
- 핵심 변경:
  1. 비거래 로직 구간 제거: `38. MODE + SCAN 패널`, `39~41 Dev 시각화/로그`
  2. 진입/청산/알림 핵심 로직 시작점(`42. Alert 펄스`)은 그대로 유지
  3. payload 필수 필드(`signal_key`, `bar_index`, `is_bar_close_confirmed`) 유지
  4. JSON 안전 처리(`f_json_escape`) 유지

## 수치 변화
- 파일 크기: `244,163 bytes -> 231,428 bytes` (약 5.22% 감소)
- 정적 점검: `PASS` (lookahead 커버리지 100%)

## TradingView 적용 절차
1. `code/donbeolja.pine.txt` 전체 복사
2. TradingView Pine Editor에 붙여넣기
