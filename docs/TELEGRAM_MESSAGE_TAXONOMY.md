# Telegram Message Taxonomy

## 목적
- 메시지 수를 줄이고, 중요한 메시지만 바로 보이게 한다.
- 기준은 `서버 신호 / 거래 / 운영 경보 / OpenClaw 요약`이다.
- 튜닝 상세와 주간 엔진 상세는 기본적으로 개별 발송하지 않는다.

## 분류
### 1. 필수
- `[목표 점검]`
- `[자동 변경 반영]`
- `[자동 롤백 점검]`
- `[일일 운영 점검]`
- `[시간별 운영 점검]`

의미:
- 목표 달성 상태
- 실제 자동 변경 반영 여부
- 롤백 발생 여부
- 일일/시간별 운영 이상 여부

### 2. 요약
- `[자동화 상태 점검]`
- `[일간·주간·월간 회고]`
- `[시간별 자산 현황]`
- `[단계별 성과 점검]`
- `[무거래 원인 분해]`
- `[기회손실 점검]`
- `[데이터 누락 복구]`
- `[데이터 무결성 점검]`
- `[자동화 변경 이상 여부 점검]`

의미:
- 보조 판단용 요약
- 경고가 아니면 기본 노출 우선순위를 낮춘다

### 3. 기본 OFF
- `[4차 EV/시간가치층 자동 조정]`
- `[5차 진입 타이밍 자동 조정]`
- `[학습 기반 필터 점검]`
- `[주간 전략 점검]`
- `[Codex 주간 패치 엔진]`
- `[Claude 주간 패치 엔진]`
- `[주간 파인 수정 검토]`
- `[주간 파인 파일 준비 완료]`
- `[청산 최적화]`

의미:
- 세부 튜닝/주간 엔진 메시지
- 개별 메시지 대신 OpenClaw 요약에 흡수한다

## 기본 정책
- 기본값: `ESSENTIAL_ONLY`
- 경고(`WARN`, `ERROR`)는 분류와 무관하게 발송 허용
- 필수 분류는 항상 발송
- 요약/기본OFF 분류는 정보성(`INFO`)이면 기본적으로 생략

## 환경 변수
- `AUTOMATION_TELEGRAM_POLICY`
  - `ESSENTIAL_ONLY`
  - `SUMMARY`
  - `ALL`
- `AUTOMATION_TELEGRAM_ALLOW_TITLES`
  - 강제 허용 제목 토큰 목록
- `AUTOMATION_TELEGRAM_MUTE_TITLES`
  - 강제 차단 제목 토큰 목록

## 현재 원칙
- `신호 메시지`, `거래 메시지`, `운영 경보`는 별도 경로에서 계속 유지한다.
- 이번 taxonomy는 `sendKoreanTelegramSummary()`를 쓰는 자동화/OpenClaw 메시지에만 적용한다.
